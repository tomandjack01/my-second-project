┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔧 关键参数                                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  通用参数:
    --csv_path PATH              fMRI 数据路径
    --epochs N                   训练轮数 (默认: 100)
    --lr FLOAT                   学习率 (默认: 1e-3)
    --lambda_l1 FLOAT            L1 正则化系数 (默认: 0.1)
    --num_hidden N               隐藏层维度 (默认: 64)
    --num_layers N               GNN 层数 (默认: 2)
    --batch_size N               批大小 (默认: 4)

  编码器控制:
    --disable_temporal_encoder   🆕 禁用时序编码器
    --skip_pretrain              跳过预训练（不推荐）
    --pretrain_epochs N          预训练轮数 (默认: 50)
    --pretrain_lr FLOAT          预训练学习率 (默认: 1e-3)
    --pretrain_checkpoint PATH   加载预训练权重

┌─────────────────────────────────────────────────────────────────────────────┐
│ 💡 使用建议                                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  ✅ 推荐禁用编码器的场景:
    • 数据维度不高 (T < 300)
    • 快速原型开发和实验
    • 需要保留完整时序信息
    • 避免编码器崩溃问题

  ✅ 推荐启用编码器的场景:
    • 高维时序数据 (T > 500)
    • 计算资源有限
    • 需要更快收敛
    • 生产环境部署

┌─────────────────────────────────────────────────────────────────────────────┐
│ ⚠️ 常见问题                                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  Q: 禁用编码器后 Loss 更高？
  A: 正常现象。200 维重构比 64 维更难。关注收敛趋势，不是绝对值。

  Q: 编码器出现崩溃警告？
  A: 如果编码器已冻结，不影响训练。或使用 --disable_temporal_encoder。

  Q: 训练速度慢？
  A: 禁用编码器时，可减少 --num_layers 或 --num_hidden 加速。

  Q: 如何选择模式？
  A: 小数据集 (N<50, T<300) → 禁用编码器
     大数据集 (N>100, T>500) → 启用编码器
